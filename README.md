# Oscar Chinchilla — Growth Marketer | Portfolio (v4)

Landing estática orientada a reclutadores. HTML/CSS/JS sin build ni dependencias. Imágenes tomadas de `Presentacion_Oscar_v1(1).html` aportada por el usuario, convertidas a WebP.

## Publicación con GitHub Pages

1. Crear un repositorio público `oscar-growth-portfolio` (o usar el existente).
2. Subir **todo el contenido**: `index.html`, `.nojekyll` y carpeta `assets/`. No subir la carpeta contenedora al nivel superior del repo.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. El enlace típico es `https://TU-USUARIO.github.io/oscar-growth-portfolio/`, si ese es el nombre del repositorio.

## Evidencia y límites de atribución

- **Extragas, julio 2026:** cifras de auditoría/diagnóstico ya documentadas en CV previo (46.441 impresiones, 129 términos sin conversión, 23% de presupuesto en esos términos, CTR Search 6,75% vs Display 1,84%). El usuario declara haber administrado y mejorado el presupuesto de la cuenta. En ausencia de reportes antes/después **no se afirma ahorro realizado, ROAS aumentado ni crecimiento causado por intervención**. En web no se publica importe total de la cuenta. La foto de Extragas proviene de la presentación.
- **Facturación comercial 2022–2024:** $272 millones 2022, $682 millones 2023 y $1.127 millones enero-octubre 2024. Captura de empresa durante etapa laboral. No es Extragas, no es gasto de anuncios ni facturación de DigitAI Motor. El archivo no confirma la moneda ni la empresa.
- **Ecommerce:** se incluyen las dos capturas aportadas. Los importes son ingresos reportados en los tableros, no métricas de ROAS ni utilidad neta. Evitar afirmar incrementos causados exclusivamente por publicidad si no hay datos de atribución.
- **Clinicas:** sección explícitamente conceptual: es un plan de trabajo y no un caso de clínicas ya gestionado.
